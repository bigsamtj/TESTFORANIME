# MY EXPERTISE — Responsive Image Hero

This version is built directly around the supplied final MY EXPERTISE artwork.

## Files
- `index.html` — responsive hero and accessible navigation
- `style.css` — exact-image presentation, responsive behavior and subtle HUD animation
- `script.js` — pointer/interaction hooks
- `my-expertise-hero.png` — the supplied artwork used as the hero source

## Run
Open `index.html` directly in a browser, or serve the folder with any local web server.

The original artwork is preserved. The HTML adds responsive behavior, subtle motion, and invisible clickable expertise zones without redrawing the supplied design.
